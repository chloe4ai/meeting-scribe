# MeetingScribe

Local meeting transcription for macOS (Swift package). Build and test on macOS: `swift build`, `swift test`.

## Agent harness

This repo carries a seat harness for Claude Code in `harness/` (see `harness/README.md`).
Commands: `/goal` writes a finish line, `/run` executes it, `/audit` reviews past runs.
